Hoe maak ik een token?
  1. Ga op GitHub naar Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories en kies UptimeData en UptimeMonitoring.
  3. Permissions → Repository permissions → Contents: Read and write. Verder niets.
  4. Kies een vervaldatum, maak het token aan en plak het hierboven.
